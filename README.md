# sql_data_warehouse_project
A data warehouse project built to get hands on experience as a data engineer. This warehouse is built using the medallion architecture. Core tools include sql, data modelling techniques...


Welcome to my first 'Data' project which is about building a Data Warehouse. The source of our data are csv files stores as CRM and ERP. I am working with MySQL database management system with client MySQL Workbench. I am to learn a lot from this project. Already I know things necessary to progress in production environment like planning the project in 'Notion', creating the data architecture diagram using 'Draw.io' and then using GIT as a version control system for all my commits.
